## 先知道这是什么

这个系统主要做两件事：

1. `教材提词`
   从带明显标注的教材里提取重点英文词或词组，生成 Excel 词表。
2. `课后反馈`
   根据课堂音频、逐字稿或补充笔记，生成可编辑的课后反馈草稿。

当前页面只保留两个工作标签页：

- `教材提词`
- `课后反馈`

`系统配置` 页面已经隐藏。
如果需要更换密钥、模型地址或其他运行参数，请联系维护者处理。

## 启动方式

如果你拿到的是打包好的 `vocab-sheet-service.exe`：

1. 双击 `vocab-sheet-service.exe`
2. 等浏览器自动打开 `http://127.0.0.1:8000/`
3. 在页面中开始使用

如果浏览器没有自动打开，可以手动访问：

```text
http://127.0.0.1:8000/
```

## 页面说明

页面主要分成两块：

| 区域 | 作用 |
| --- | --- |
| 左侧主操作区 | 上传文件、填写补充内容、生成结果 |
| 右侧状态区 | 显示当前任务进度、阶段、结果摘要 |

顶部有两个标签页：

| 标签页 | 用途 |
| --- | --- |
| `教材提词` | 上传教材并生成 Excel 词表 |
| `课后反馈` | 生成并编辑课后反馈草稿 |

## 教材提词

### 使用前准备

系统只会优先提取“被明显标注”的英文词或词组。
请尽量保证教材中的重点内容有清晰标记。

支持的教材文件：

- `.pdf`
- `.docx`

系统识别重点时，优先依赖这些标记：

- 红字
- 下划线
- 批注
- 框选
- 高亮

如果是词组，建议连续标注整段词组，不要只标其中一部分。

### 操作步骤

1. 进入 `教材提词`
2. 在 `上传教材` 区域选择 `.pdf` 或 `.docx`
3. 如有需要，在 `语音上传入口` 上传音频，辅助补词
4. 如有需要，在 `手工补词` 中直接输入单词或词组
5. 如需用麦克风补词，可点击 `点麦补词`
6. 点击 `开始生成词表`
7. 观察右侧状态区，等待任务完成
8. 系统完成后会自动下载 Excel 文件

### 手工补词说明

手工补词支持：

- 逗号分隔
- 分号分隔
- 换行分隔

例如：

```text
apple, improve, growth mindset
```

### Excel 词表生成规则

生成的 Excel 会尽量补齐每个词条的音标、词性、中文意思和例句。
如果教材里能找到原句，系统会使用教材原句，并填写原句所在页数。

如果教材里找不到例句，系统会自动造一句贴合单词语义的英文例句，
同时把页数字段留空，便于区分这句不是教材原句。

示例：

| 单词 | 自动生成例句 |
| --- | --- |
| `afraid` | `My brother was afraid of it, but it didn't come anywhere near us.` |
| `upset` | `She was upset because she lost her favorite notebook.` |
| `several` | `Several students stayed after class to ask questions.` |
| `yet` | `I haven't finished my homework yet.` |

例句中的目标词会自动加粗并略微放大，方便检查和课堂使用。

### 右侧状态区会显示什么

教材提词任务通常会经历这些阶段：

1. `上传校验`
2. `教材解析`
3. `音频/补词合并`
4. `词典补全`
5. `例句定位`
6. `模板写入`
7. `准备下载`

## 课后反馈

### 输入要求

以下两项至少提供一个：

- 课堂音频
- 逐字稿 / 补充笔记

### 操作步骤

1. 进入 `课后反馈`
2. 填写 `上课日期`
3. 填写 `节次`
4. 选填 `班级 / 课程名`
5. 上传课堂音频，或粘贴逐字稿 / 补充笔记
6. 点击 `开始生成反馈`
7. 等待右侧状态区显示完成
8. 在下方编辑生成出来的反馈草稿

### 草稿能做什么

生成完成后，你可以：

- 直接修改每个模块内容
- 单独重生成某一个模块
- 点击 `复制全文`
- 点击 `复制作业`

### 反馈任务阶段

课后反馈任务通常会经历这些阶段：

1. `整理源材料`
2. `音频转写`
3. `生成反馈草稿`
4. `草稿可编辑`

## 结果怎么看

### 教材提词结果

完成后可以看到两个结果标签：

| 标签 | 含义 |
| --- | --- |
| `写入明细` | 已成功写入 Excel 的词条 |
| `处理异常` | 某些词条存在附加说明或异常原因 |

页面还会显示：

- `输出文件`
- `写入词数`
- `处理异常数`

### 什么叫“处理异常”

这不一定代表整份结果失败。
常见情况包括：

- 找到了词，但没有在教材正文里定位到例句
- 词条成功写入了表格，但某些字段补全不完整

只要 Excel 正常生成，通常就还能继续使用。

### Excel 结果的基本规则

生成的 Excel 会自动：

- 使用固定模板
- 以教材文件名作为输出文件名基础
- 在表格中写入单词、音标、词性、中文意思、例句、页码和来源
- 对例句里的目标词或词组进行加粗和放大
- 在找不到教材例句时自动生成语义贴合的例句，并让页码为空

## 常见问题

### 为什么上传成功了，但没有生成词表

优先检查：

1. 教材里是否真的做了明显标注
2. 标注的是不是英文词或连续词组
3. 上传的文件是不是 `.pdf` 或 `.docx`
4. 是否完全没有手工补词

### 为什么有些词在“处理异常”里，但 Excel 还是生成了

这是正常情况。
它通常表示某个词条存在附加说明，不代表整份结果失败。

### 点麦补词没有反应怎么办

先检查：

1. 浏览器是否允许麦克风权限
2. 当前浏览器是否支持录音
3. 麦克风是否被其他程序占用

如果不方便使用麦克风，可以直接在文本框里手工输入单词。

### 课后反馈生成慢正常吗

正常。
如果上传了音频，系统通常还需要先完成转写，再生成反馈草稿。

### 第一次启动或第一次处理为什么更慢

正常。
打包版虽然已经内置了必要资源，但首次启动仍可能有解包和初始化过程。

- 页面打不开
