# 用户操作手册

适用对象：使用“教材提词与课后反馈工作台”的老师、教务或运营同事。  
适用版本：基于当前仓库中的系统功能整理。

## 1. 系统能做什么

本系统目前提供 3 个主要功能：

1. `教材提词`
   从已标注的教材中提取重点英文词或词组，补全音标、词性、中文意思和例句，并生成 Excel 词表。
2. `课后反馈`
   根据课堂音频、逐字稿或补充笔记，自动生成可编辑的课后反馈草稿。
3. `系统配置`
   维护 `VISION_API_KEY`、模型地址、模型名称和超时参数。

## 2. 快速开始

1. 启动服务后，在浏览器打开：

```text
http://127.0.0.1:8000/
```

2. 首次使用时，先进入 `系统配置` 页面。
3. 填写或确认 `VISION_API_KEY`、`VISION_BASE_URL`、`VISION_MODEL` 等参数。
4. 先点击 `测试连接`，校验通过后再点击 `保存配置`。
5. 回到 `教材提词` 或 `课后反馈` 页面开始使用。

> 建议配图：系统首页整体界面

## 3. 界面总览

页面主要分为两部分：

| 区域 | 作用 |
| --- | --- |
| 顶部标签页 | 在 `教材提词`、`课后反馈`、`系统配置` 之间切换 |
| 左侧主操作区 | 上传文件、填写参数、编辑结果 |
| 右侧任务状态区 | 显示当前任务阶段、进度、结果摘要和重新下载入口 |

说明：

- 右侧任务状态会显示当前任务的处理阶段。
- 如果页面刷新，系统会尝试恢复当前任务进度显示。
- `教材提词` 完成后会自动下载 `.xlsx` 文件。

## 4. 教材提词

### 4.1 使用前准备

系统只会提取“被明确标注”的英文词或词组。请先确认教材处理方式符合要求：

- 支持文件类型：`.pdf`、`.docx`
- `DOCX` 优先识别：连续红字、下划线、批注
- `PDF` 可识别：红字、下划线、框选、高亮等明显强调
- 只提取被明确标注的英文词或词组
- 如果是词组，必须连续标注
- 如果 `DOCX` 主要依赖“背景色高亮”，建议先转成 `PDF` 再上传

### 4.2 操作步骤

1. 进入 `教材提词` 页面。
2. 在 `上传教材` 区域点击 `选择教材文件`，上传 `.pdf` 或 `.docx` 文件。
3. 如果需要补充候选词，可在 `语音上传入口` 上传课堂或朗读音频。
4. 如果还需要人工补充，可在 `手工补词` 中直接输入单词或词组。
5. 如果使用浏览器麦克风补词，点击 `点麦补词`。
6. 浏览器弹出权限提示时，允许麦克风访问。
7. 再次点击按钮即可结束录音并自动识别补词结果。
8. 点击 `开始生成词表`。
9. 观察右侧状态区，等待任务完成。
10. 系统完成后会自动下载 Excel 文件。

> 建议配图：教材提词页面的“上传教材 + 手工补词 + 开始生成词表”区域

### 4.3 处理阶段说明

右侧状态区会依次显示以下阶段：

1. `上传校验`
2. `教材解析`
3. `音频/补词合并`
4. `词典补全`
5. `例句定位`
6. `模板写入`
7. `准备下载`

### 4.4 结果怎么看

任务完成后，可以查看两个结果页签：

| 页签 | 含义 |
| --- | --- |
| `写入明细` | 已成功写入词表的词条 |
| `处理异常` | 处理时出现异常说明，但不一定代表整份词表生成失败 |

结果区还会显示：

- `输出文件`：下载得到的文件名
- `写入词数`：成功写入模板的词条数量
- `处理异常数`：出现异常说明的词条数量

如果需要再次下载，可点击 `重新下载`。

### 4.5 输出 Excel 规则

生成的 Excel 使用固定模板 `template/单词表模板.xlsx`，并遵循以下规则：

- 下载文件名：`教材文件名.xlsx`
- 第一行标题：使用上传教材文件名，不含扩展名
- 表头字段固定为：

| 列名 | 说明 |
| --- | --- |
| 序号 | 自动编号 |
| 单词 | 提取或补充得到的词条 |
| 音标 | 本地词典补全结果 |
| 词性 | 本地词典补全结果 |
| 中文意思 | 本地词典补全结果 |
| 例句 | 从教材正文定位到的例句，或系统生成的占位例句 |
| 例句在教材中出现的页数 | 例句所在页码 |
| 来源 | 教材 / 手工补词 / 音频补词 |

来源字段可能出现的值：

| 来源标签 | 含义 |
| --- | --- |
| `教材` | 词条来自教材标注 |
| `手工补词` | 词条来自手工输入或点麦补词 |
| `音频补词` | 词条来自上传音频识别 |
| `教材 / 手工补词` 等组合 | 同一词条同时来自多个来源 |

### 4.6 常见结果情况

1. `教材中找到了词，也找到了例句`
   会正常写入词表，例句和页码一起写入。
2. `教材中找到了词，但没找到例句`
   该词仍会写入词表，但会在 `处理异常` 中提示 `未在教材正文中定位到例句`。
3. `手工补词在教材正文中存在`
   会正常写入，并优先使用教材中的真实例句。
4. `手工补词不在教材正文中`
   该词仍会写入词表，系统会生成占位例句：

```text
The term {单词} is used in this lesson.
```

5. `本地免费词典没查到释义`
   该词仍会写入词表，但音标、词性、中文意思可能为空，并在 `处理异常` 中提示 `本地免费词典未找到该单词释义`。

### 4.7 失败时优先检查什么

- 教材中是否真的做了明确标注
- 上传的是否是 `.pdf` 或 `.docx`
- 如果是词组，是否连续标注
- 如果没有做教材标注，是否至少在 `手工补词` 中补入了词

如果系统提示：

```text
未识别到可回填的单词。当前只会从教材中的红字、下划线、批注，或手动补充单词中取词。
```

通常说明教材中没有可识别标记，或没有补充手工词。

## 5. 课后反馈

### 5.1 输入要求

生成课后反馈时，至少提供以下二者之一：

- `课堂音频`
- `逐字稿 / 补充笔记`

如果两者都不提供，系统会直接报错。

### 5.2 操作步骤

1. 进入 `课后反馈` 页面。
2. 填写 `上课日期`。
3. 填写 `节次`。
4. 选填 `班级 / 课程名`。
5. 选择以下任一输入方式：
   `课堂音频`：适合直接根据录音生成反馈。
   `逐字稿 / 补充笔记`：适合人工整理后快速生成反馈。
6. 如果音频和文字都提供，系统会自动合并两部分内容生成草稿。
7. 点击 `开始生成反馈`。
8. 等待右侧状态区显示完成。
9. 在页面下方查看并编辑反馈草稿。

> 建议配图：课后反馈页面的“音频上传 + 逐字稿输入 + 开始生成反馈”区域

### 5.3 处理阶段说明

课后反馈任务通常会经历以下阶段：

1. `整理源材料`
2. `音频转写`
3. `生成反馈草稿`
4. `草稿可编辑`

### 5.4 草稿包含哪些模块

反馈草稿默认包含 5 个模块：

| 模块 | 说明 |
| --- | --- |
| `抬头` | 上课日期、节次、班级 / 课程名 |
| `本节课重点` | 用短条目概括本节课讲了什么 |
| `规则 / 句型` | 提炼语法、句型、规则或易错点 |
| `作业` | 只保留明确布置的课后任务 |
| `教师补充` | 面向家长的一段提醒、表扬或建议 |

### 5.5 编辑与复制

生成完成后，你可以：

1. 直接编辑每个模块的文本内容。
2. 点击某个模块右上角的 `重新生成本模块`，只刷新该模块内容。
3. 点击 `复制全文`，复制整份反馈草稿。
4. 点击 `复制作业`，只复制作业模块内容。

> 建议配图：课后反馈草稿编辑区与“重新生成本模块”按钮

### 5.6 使用建议

- 如果课堂音频质量一般，建议同时补充逐字稿或老师笔记。
- 如果音频与补充笔记内容不一致，以补充笔记中的明确信息为准。
- 如果只想快速出稿，没有音频，也可以只粘贴逐字稿。

### 5.7 常见异常

1. 如果系统提示 `请提供课堂音频或逐字稿文本。`
   说明两个输入都为空。
2. 如果音频转写质量太差，系统可能提示转写结果疑似异常。
3. 如果草稿内容不理想，优先尝试：
   补充更清晰的逐字稿。
   或只重新生成单个模块。

## 6. 系统配置

### 6.1 可配置项

| 字段 | 说明 |
| --- | --- |
| `VISION_API_KEY` | 视觉服务密钥 |
| `VISION_BASE_URL` | 视觉服务地址 |
| `VISION_MODEL` | 使用的视觉模型名称 |
| `REQUEST_TIMEOUT_SECONDS` | 通用请求超时 |
| `VISION_TIMEOUT_SECONDS` | 视觉模型请求超时 |
| `RUNTIME_ROOT` | 运行时缓存目录 |

### 6.2 使用步骤

1. 进入 `系统配置` 页面。
2. 如需更换密钥，在 `VISION_API_KEY` 中输入新值。
3. 如果不想修改密钥，可保持该输入框为空。
4. 按需调整模型地址、模型名称和超时参数。
5. 点击 `测试连接`。
6. 看到校验通过后，再点击 `保存配置`。

### 6.3 重要说明

- 页面中显示的密钥状态是脱敏后的，不会展示明文。
- 如果 `VISION_API_KEY` 留空，保存时会沿用当前密钥。
- `测试连接` 只验证连通性，不会保存到磁盘。
- `保存配置` 后，仅新创建的任务会使用新配置。
- 当后台仍有任务在运行时，系统不允许保存配置。

如果保存时提示：

```text
后台任务正在运行，请等待后台任务运行完成后再进行系统配置修改保存。
```

请先等待 `教材提词` 或 `课后反馈` 任务结束。

### 6.4 常见校验失败原因

| 提示 | 常见原因 |
| --- | --- |
| `视觉服务认证失败，请检查 API Key。` | API Key 不正确或已失效 |
| `连接视觉服务超时，请检查地址和超时配置。` | 网络不通、地址不可达或超时太短 |
| `无法连接视觉服务，请检查地址或网络。` | 服务地址错误，或网络无法访问 |
| `视觉服务返回 HTTP xxx` | 服务端异常、模型权限不足或网关问题 |

## 7. 常见问题

### 7.1 为什么教材上传成功了，但没有生成词表？

优先检查以下几点：

1. 教材中是否真的有红字、下划线、批注或明显高亮标注
2. 标注的是否是英文词或连续词组
3. 是否上传了错误文件
4. 是否完全没有使用 `手工补词`

### 7.2 为什么有些词出现在“处理异常”里，但 Excel 还是生成了？

这是正常情况。  
`处理异常` 只表示某些词条存在附加问题，例如：

- 没找到教材例句
- 没查到本地词典释义

只要系统还能生成整体词表，Excel 仍会正常输出。

### 7.3 浏览器点麦补词没反应怎么办？

先检查：

1. 浏览器是否允许麦克风权限
2. 浏览器是否支持网页录音
3. 麦克风是否被其他软件占用

如果仍不方便使用，直接在文本框手工输入单词即可。

### 7.4 课后反馈生成慢正常吗？

正常。  
如果上传了音频，系统通常还需要先完成转写，再生成反馈草稿。

### 7.5 第一次使用时为什么处理特别慢？

首次运行时，系统可能会自动准备词典、语音识别模型或相关运行时资源，因此会明显慢于后续使用。

## 8. 推荐操作顺序

如果你是第一次使用，建议按下面顺序操作：

1. 打开系统
2. 进入 `系统配置`
3. 点击 `测试连接`
4. 保存配置
5. 回到 `教材提词` 试跑一个小样本
6. 确认 Excel 生成正常
7. 再开始使用 `课后反馈`
